## 1. 게임 엔진 (engine/)

### 1.1 카드 시스템

| 월 | 식물 | 광 | 동물 | 띠 | 피 |
|----|------|----|------|----|----|
| 1월 | 소나무(松) | 학 | - | 홍단 | ×2 |
| 2월 | 매화(梅) | - | 꾀꼬리 | 홍단 | ×2 |
| 3월 | 벚꽃(桜) | 커튼 | - | 홍단 | ×2 |
| 4월 | 등나무(藤) | - | 두견새 | 초단 | ×2 |
| 5월 | 난초(蘭) | - | 다리 | 초단 | ×2 |
| 6월 | 모란(牡) | - | 나비 | 청단 | ×2 |
| 7월 | 싸리(萩) | - | 멧돼지 | 초단 | ×2 |
| 8월 | 억새(芒) | 달 | 기러기 | - | ×2 |
| 9월 | 국화(菊) | - | 국진 | 청단 | ×2 |
| 10월 | 단풍(楓) | - | 사슴 | 청단 | ×2 |
| 11월 | 오동(桐) | 봉황 | - | - | 쌍피 + ×2 |
| 12월 | 버들(柳) | 비 | 제비 | 띠 | 쌍피 |

- **총 48장**: 광 5, 동물 9, 띠 10, 피 21, 쌍피 3
- **특수 카드**: 국진(9월 동물) — 피 10장 이상일 때 피 2장으로 전환

### 1.2 점수 족보

| 족보 | 조건 | 점수 |
|------|------|------|
| 오광 | 광 5장 전부 | 15점 |
| 사광 | 광 4장 | 4점 |
| 비삼광 | 광 3장 (비 포함) | 2점 |
| 삼광 | 광 3장 (비 제외) | 3점 |
| 고도리 | 꾀꼬리 + 두견새 + 기러기 | 5점 |
| 홍단 | 1·2·3월 홍단 3장 | 3점 |
| 청단 | 6·9·10월 청단 3장 | 3점 |
| 초단 | 4·5·7월 초단 3장 | 3점 |
| 동물 | 5마리 이상 | (N-4)점 |
| 띠 | 5장 이상 | (N-4)점 |
| 피 | 10장 이상 | (N-9)점 |

- 모든 족보는 **중복 적용** (예: 홍단 + 띠 5장 동시 가능)

### 1.3 배수 시스템

| 배수 | 조건 | 효과 |
|------|------|------|
| 피박 | 패자 피 ≤5장 | ×2 |
| 광박 | 패자 광 0장 | ×2 |
| 고박 | 패자가 고를 선언한 적 있음 | ×2 |
| 흔들기 | 승자 손패에 같은 월 3장 이상 | ×2 |
| 멍따 | 승자 동물 7마리 이상 | ×2 |

- **고 보너스**: 고 횟수만큼 기본 점수에 추가
- **최종 점수**: `(기본점수 + 고보너스) × 배수`

### 1.4 게임 진행 단계

```
Play → Capture → (GoStop) → Play → ...→ End
```

| 단계 | 설명 |
|------|------|
| Play | 손패에서 카드 1장 선택, 바닥 매칭 |
| Capture | 덱에서 1장 뒤집기, 바닥 매칭 후 획득 |
| GoStop | 점수 도달 시 고/스톱 선택 |
| End | 승리/무승부 결정, 결과 계산 |

### 1.5 매칭 규칙

| 매칭 수 | 처리 |
|---------|------|
| 0장 | 바닥에 카드 놓기 |
| 1장 | 자동 획득 |
| 2장 | 플레이어가 선택 |
| 3장 | 전부 획득 (뻑) |

### 1.6 특수 규칙

| 규칙 | 설명 |
|------|------|
| 쓸 (싹쓸이) | 바닥 카드 전부 가져가면 쓸 +1, 상대 피 1장 뺏기 |
| 총통 | 같은 월 4장이 손패에 있으면 선언 가능 |
| 흔들기 | 같은 월 3장이 손패에 있을 때 보너스 |

### 1.7 게임 설정 (GameConfig)

| 설정 | 기본값 | 설명 |
|------|--------|------|
| scoreThreshold | 3 | 고/스톱 진입 기준 점수 |
| useSsangpi | true | 쌍피 사용 |
| useBomb | true | 뻑/폭탄 사용 |
| useSwing | true | 흔들기 |
| useChongtong | true | 총통 |
| usePiSteal | true | 피뺏기 |
| useSweep | true | 쓸 |
| useGwangBak | true | 광박 |
| usePiBak | true | 피박 |
| useGoBak | true | 고박 |
| useMungTung | true | 멍따 |
| useGodori | true | 고도리 |

- **프리셋**: Standard (서울 표준), Fast (7점 기준, 일부 비활성)

## 2. AI 시스템

### 2.1 난이도

| 난이도 | 최적 수 확률 | 고 공격성 | 설명 |
|--------|-------------|-----------|------|
| Easy | 50% | 낮음 | 나머지 랜덤 |
| Normal | 80% | 보통 | 20% 차선택 |
| Hard | 100% | 70% | 항상 최적 수 |

### 2.2 전략 평가 기준

- **광**: 삼광 접근 시 가중치 15, 기본 8
- **동물**: 고도리 조합 추적 (2마리 5점, 3마리 10점 보너스)
- **띠**: 홍단/청단/초단 세트 추적 (2장 접근 시 보너스)
- **피**: 10장 임계치 접근 시 가중치 상승
- **고/스톱**: 잔여 덱, 상대 점수, 보너스 근접도 종합 판단

## 3. UI / 연출 시스템

### 3.1 카드 렌더링

| 항목 | 구현 |
|------|------|
| 카드 스타일 | 3종 (Classic/Simple/Widget 기반) |
| 월 번호 오버레이 | 카드 우상단 `N월` 반투명 배지 |
| 매칭 가능 테두리 | 연두색 테두리 + 글로우 |
| 선택 상태 | 파란 테두리 + 위로 8px 이동 |
| 하이라이트 | 주황 테두리 + 글로우 |
| 매칭 불가 흐림 | opacity 0.4 (내 턴 중) |
| 롱프레스 확대 | 3배 크기(156×216) 다이얼로그 |

### 3.2 이벤트 연출 (애니메이션 오버레이)

| 이벤트 | 연출 | 지속시간 |
|--------|------|----------|
| 쓸 (sweep) | "쓸!" 텍스트 + 확대→페이드 | 800ms |
| 고 (goChosen) | "N고!" + 슬라이드업 + 탄성 스케일 | 1200ms |
| 스톱 (stopChosen) | "스톱!" + 빨간 그라데이션 | 1200ms |
| 뻑 (tripleMatch) | "뻑!" + 좌우 떨림(6회) + 탄성 확대 | 1000ms |
| 폭탄 (bomb) | "폭탄!" + 좌우 떨림 + 빨간 글로우 | 1000ms |

**이벤트 우선순위**: 쓸 > 뻑 > 폭탄

**뻑 발생 조건**: 바닥에 같은 월 카드 3장이 있을 때 매칭
**폭탄 발생 조건**: 낸 카드와 덱에서 뒤집힌 카드가 같은 월 (따닥)

### 3.3 점수판

| 항목 | 표시 |
|------|------|
| 현재 점수 | N점 (큰 폰트) |
| 활성 턴 | 녹색 테두리 + 배경 |
| 고 횟수 | 주황-빨간 그라데이션 배지 |
| 배율 표시 | ×N (앰버색 볼드, 고 횟수+1) |
| 잔여 덱 | 가운데 큰 숫자 |

### 3.4 족보 진행률 (획득 카드 영역)

족보별 진행 상태를 칩으로 표시:

| 족보 | 표시 방식 | 색상 |
|------|-----------|------|
| 삼광~오광 | ●●○ (도트) | 금색 |
| 고도리 | ●○○ (도트) | 녹색 |
| 홍단 | ●●○ (도트) | 빨간색 |
| 청단 | ●○○ (도트) | 파란색 |
| 초단 | ●●○ (도트) | 주황색 |
| 피 | 7/10 (숫자) | 회색 |

- 완성 시: 테두리 + 배경 강화
- 미완성: 반투명 표시

### 3.5 턴 흐름 메시지

| 상황 | 메시지 |
|------|--------|
| 2장 매칭 선택 | "가져갈 카드를 선택하세요" |
| 뒤집힌 카드 매칭 | "뒤집힌 카드(이름)를 매칭하세요" |
| AI 턴 | "AI 턴..." |
| 상대 턴 (온라인) | "상대 턴..." |
| 고/스톱 선택 | "N점 (×M)! 고 하시겠습니까?" |
| 고 선택 | "N고!" |
| 게임 종료 | "승리!" / "패배..." / "무승부!" |

### 3.6 바닥 카드 영역

- 월별 그룹핑 (같은 월 카드 묶음 표시)
- 2장 이상 시 반투명 테두리 그룹 박스
- 월 번호 배지 표시
- 롱프레스 확대 지원

### 3.7 결과 다이얼로그

| 항목 | 내용 |
|------|------|
| 제목 | 승리(앰버) / 패배(빨강) / 무승부(흰색) |
| 점수 비교 | 나 vs AI(상대) 점수 |
| 배수 정보 | ×N + 적용 사유 칩 |
| 전적 | 승/패/무 + 승률% + 연승 |
| 버튼 | 로비로 / 다시 하기 |

## 5. P2P 온라인 대전

### 5.1 연결 방식

```
Player A ──WebSocket──→ Signaling Server ←──WebSocket── Player B
    │                                              │
    └─────── WebRTC DataChannel (P2P) ─────────────┘
```

### 5.2 매칭 방법

| 방법 | 흐름 |
|------|------|
| 방 만들기 | 6자리 코드 생성 → 공유 → 상대 입장 대기 |
| 방 참가 | 코드 입력 → 즉시 연결 |
| 랜덤 매칭 | 큐 등록 → 서버가 자동 매칭 |

- **코드 문자**: `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (혼동 방지: I/O/0/1 제외)

### 5.3 Host-Client 모델

| 역할 | 담당 |
|------|------|
| Host (P0) | 게임 상태 관리, 덱 셔플(seed), 입력 검증 |
| Client (P1) | 입력 전송, 상태 수신 |

### 5.4 메시지 프로토콜

| 타입 | 방향 | 용도 |
|------|------|------|
| gameInit | Host→Client | seed + config 전송 |
| playCard | 양방향 | 카드 플레이 |
| selectMatch | 양방향 | 2장 매칭 선택 |
| selectCaptureMatch | 양방향 | 캡처 매칭 선택 |
| chooseGo | 양방향 | 고 선택 |
| chooseStop | 양방향 | 스톱 선택 |
| ping/pong | 양방향 | 연결 유지 |
| stateHash | 양방향 | 동기화 검증 |
| syncRequest | 양방향 | 재동기화 요청 |
| fullSync | Host→Client | 전체 상태 전송 |

### 5.5 시그널링 서버

- **기술**: Node.js + ws (WebSocket)
- **포트**: 3000
- **기능**: 방 관리, 매칭 큐, WebRTC 시그널 중계
- **헬스체크**: `/health`
- **하트비트**: 30초 ping/pong

### 5.6 온라인 전용 기능

- 연결 상태 인디케이터 (녹/빨)
- 상대 연결 끊김 다이얼로그 (30초 타이머)
- 모든 연출 효과 동기화 (쓸/뻑/폭탄/고스톱)
